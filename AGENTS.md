# Работа с общим SMS-модулем

Этот репозиторий — канонический источник SMS-входа для всех проектов. Правки, обнаруженные в любом проекте, вноси сюда; не создавай независимые копии в темах и MU-плагинах.

- Сохраняй WordPress/WooCommerce API, совместимые функции `moto_*` и метаданные существующих пользователей.
- Перед публикацией запускай `python scripts/test.py` и `python scripts/build.py`; для изменений интерфейса проверяй браузер desktop/mobile.
- Пользователь разрешил публичный репозиторий и автоматические проверенные релизы этого модуля. После завершённой scoped-правки публикуй её в `main`, если для конкретной задачи не указан local-only или иной запрет. Не используй force-push. При работе в ветке разреши конфликты и сохрани чужие изменения до merge.
- Push кода в `main` запускает автоматический релиз GitHub Actions. Дождись результата CI и релиза; проверь версию, архив и SHA-256. Номер версии повышается workflow, вручную меняй его только для осознанного minor/major.
- Каждый подключённый WordPress хранит собственные настройки и получает релизы. Не записывай настройки одного сайта поверх другого и не размещай write-токен GitHub на сайтах.
- Ключи API, salts, `wp-config.php`, базы, cookies и данные покупателей не входят в Git/ZIP/логи. Тестовые токены генерируй внутри тестов.
- Для миграции Motonaklejki используй её проектный guarded installer и pinned SSH helper. Настоящие SMS, входы пользователей и заказы для smoke-тестов не создавай.
